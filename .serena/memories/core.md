# Core — dotfiles_pc

Cross-platform (Linux + Windows) personal dotfiles managed by Dotter (Handlebars templating). Config-as-data, not an app codebase.

**Read `AGENTS.md` at repo root first** — it is the canonical, complete reference: full directory-to-target map, dotter workflow, templating, shell setup, conventions.

Non-obvious invariants (beyond AGENTS.md):
- Deployed configs are symlinks into this repo (`default_target_type = "automatic"`) — repo edits are live instantly; only template-type targets (e.g. rio) need `dotter deploy` re-run
- Secrets/API keys: `{{VAR}}` templating sourced from KeePassXC via gitignored `.dotter/local.toml` — never hardcode, never commit
- OS gating: `[linux.files]` / `[windows.files]` sections in `.dotter/global.toml`

Maintenance rule: AGENTS.md is regenerated by the OpenCode /init command, which knows nothing about these memories. After any AGENTS.md update, review these memories: prune anything now covered by AGENTS.md, re-point references, and keep only still-non-obvious deltas. Never duplicate AGENTS.md content here.

Further: `mem:conventions` (extra style rules + gotchas), `mem:task_completion` (done-checklist). Stack: `mem:tech_stack`; commands: `mem:suggested_commands`.
